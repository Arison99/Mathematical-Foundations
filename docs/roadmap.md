# Roadmap

This roadmap separates current repository state from possible future work. Items remain planned until the relevant documentation or code is present and reviewed.

## Current state

- The repository contains a root overview and the existing GNU GPL version 3 license.
- No concept pages, language implementations, or tests are present.
- Root contribution and documentation conventions are being established.

## Planned

1. Review and refine the contribution, pseudocode, architecture, and documentation standards.
2. Add the first researched concept under a suitable mathematical domain, with references, assumptions, examples, pseudocode, correctness reasoning, and complexity analysis.
3. Select implementation languages based on contributor interest and document actual requirements and verification for each contribution.
4. Add shared fixtures or conformance checks when multiple implementations make them useful.

New mathematical domains and languages can be proposed as the project grows; this list does not imply that any are implemented.
