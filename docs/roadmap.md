# Roadmap

This roadmap separates current repository state from possible future work. Items remain planned until the relevant documentation or code is present and reviewed.

## Current state

- The repository contains a root overview and the existing GNU GPL version 3 license.
- The GCD concept has theory, pseudocode, examples, an independent-study proof worksheet, and Python and C++ implementations with tests.
- Root contribution and documentation conventions are established.

## Planned

1. Independently complete and review the GCD proof worksheet.
2. Add researched number-theory concepts, such as extended GCD, in separate scoped tasks.
3. Select additional implementation languages based on contributor interest and document actual requirements and verification for each contribution.
4. Add shared fixtures or conformance checks when they are useful across several concepts or implementations.

New mathematical domains and languages can be proposed as the project grows; this list does not imply that any are implemented.
