# Security policy

No executable project code is currently maintained in this repository. If you identify a security issue in a future implementation or its documentation, please report it privately to the repository owner through the private reporting mechanism provided by the hosting service, if available. Do not include sensitive details in a public issue.

There is no dedicated security response team or guaranteed response time. If private reporting is unavailable, use the hosting service's security reporting process rather than publishing an exploit in an issue.
